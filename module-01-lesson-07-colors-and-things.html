Transcription

Part 01

Maple: What is red?

Vale: Apples are red. Fire trucks are red.

Maple: What is green?

Vale: Leaves are green. Grass is green.

Maple: O que é vermelho?

Vale: Maçãs são vermelhas. Caminhões de bombeiros são vermelhos.

Maple: O que é verde?

Vale: Folhas são verdes. Grama é verde.

Part 02

Vale: What is blue?

Maple: The ocean is blue. The sky is blue.

Vale: What is brown?

Maple: Chocolate is brown. Some dogs are brown.

Vale: O que é azul?

Maple: O oceano é azul. O céu é azul.

Vale: O que é marrom?

Maple: Chocolate é marrom. Alguns cachorros são marrons.

Part 03

Maple: What is yellow?

Vale: The sun is yellow. Bananas are yellow.

Maple: What is orange?

Vale: Carrots are orange. Pumpkins are orange.

Maple: O que é amarelo?

Vale: O sol é amarelo. Bananas são amarelas.

Maple: O que é laranja?

Vale: Cenouras são laranjas. Abóboras são laranjas.

Part 04

Vale: What is pink?

Maple: Some flowers are pink. Flamingos are pink.

Vale: What is purple?

Maple: Grapes are purple. Some flowers are purple.

Vale: O que é rosa?

Maple: Algumas flores são rosas. Flamingos são rosas.

Vale: O que é roxo?

Maple: Uvas são roxas. Algumas flores são roxas.

Part 05

Maple: What is black?

Vale: The night sky is black. Some cats are black.

Maple: What is white?

Vale: Snow is white. Clouds are white.

Maple: O que é preto?

Vale: O céu noturno é preto. Alguns gatos são pretos.

Maple: O que é branco?

Vale: A neve é branca. As nuvens são brancas.
